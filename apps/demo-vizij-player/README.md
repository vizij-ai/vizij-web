# demo-vizij-player

Authoring surface for experimenting with Vizij’s high-level facial rigs, orchestrator graph merges, and lightweight animation clips within the `demo-vizij-player` app.

## Scripts

- `pnpm dev` – start the local dev server.
- `pnpm build` – build the production bundle.
- `pnpm preview` – preview the production build.
- `pnpm typecheck` – run TypeScript in `--noEmit` mode.
- `pnpm lint` – run ESLint across the project.
- `pnpm test` – execute the Vitest suite (currently placeholder).
