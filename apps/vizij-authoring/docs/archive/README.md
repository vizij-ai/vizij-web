# Vizij Authoring Docs Archive

This folder stores historical docs that are no longer active execution sources.

## Contents

1. `apps/vizij-authoring/docs/archive/plans/` — superseded planning snapshots.
2. `apps/vizij-authoring/docs/archive/notes/` — historical investigations/reviews.
3. `apps/vizij-authoring/docs/archive/reports/` — evidence reports and one-off deep audits.

## Usage Rules

1. Use archive docs for historical context only.
2. Do not execute from archive docs directly.
3. Promote any still-relevant action into active docs under `docs/plans/`.
